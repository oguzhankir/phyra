The bundled application combines this source with GPL-covered Gmsh and
SolveSpace. Distribution of the combined application must comply with GPLv3
and the applicable third-party terms; it is not an Apache-only binary.
The GPLv3 text is retained in notices/GPL-3.0.txt. Apache-2.0 is compatible

remove the dependencies' copyleft obligations. Previous GPL-3.0-or-later
releases retain the rights already granted to recipients.

The managed engine includes Gmsh 4.15.2 (GPL-2.0-or-later with the
Gmsh exception), Python (PSF license), NumPy and SciPy (BSD licenses),
scikit-fem 12.0.2 (BSD-3-Clause license), PyTorch 2.14.0 (BSD-style license),
and JSON Schema validation libraries. Gmsh's native library embeds other
components; its original LICENSE and CREDITS are retained alongside the
corresponding source-license texts. The Gmsh exception is limited to the
upstream components named in that exception.

Packaging copies licenses and copyright notices from the exact installed
Python distributions and frontend packages into resources/licenses. It also
records the resolved versions. The application includes these legal resources.

The CAD worker adds cadquery-ocp-novtk 8.0.1.1.0 (OpenCASCADE bindings)
and a headless SolveSpace 3.2 C ABI. Their original notices, pinned build
recipes and source manifests are retained in this repository and generated
legal inventory; setup retains source archives under artifacts/. The macOS
native CAD audit identifies the wheel's native dependencies. Exact upstream
pybind11/RapidJSON header revisions remain unverified because its recipe
resolved wildcard versions. Windows CAD dependencies are not yet audited.
Public installer staging requires both the target audit and verified exact
source provenance; these development packages do not satisfy that gate.

Before redistributing any installer, provide its complete Corresponding Source,
including Phyra, the exact Gmsh native source and embedded copyleft components,
the bundled CAD kernels and their dependencies,
and the scripts/toolchain information needed to rebuild it. Hosting the same
source alongside a binary is one route under GPLv3 section 6(d); a generic
upstream link alone is not a source offer. No source-offer service or public
binary release is configured here. Review the generated native and Rust
dependency inventory for the target package before public redistribution.
